One funny line entry for make.fun's "One Line, Big Laugh" bounty, $2 in USDC. The program writes a single hilarious line — at most 200 characters, no title, setup or explanation — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

`main.ts` validates the line (1–200 characters, single line, no control characters, no leading/trailing whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
